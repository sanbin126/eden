# 番外 · 没有说出口的话

> 说明：本章按剧本原文录入，与游戏内 JSON 一致。

**简介：**夜路上，你在口袋里摸到一张贴在瓶盖上的小小便签。

## 场景 · scene_walk　公寓外 · 夜风

你离开中野家之后，走出公寓大门。夜风从领口灌进来，你把外套拉链拉到顶，朝车站的方向走。

（背景切换 → 街道 · 路灯 · 夜）

走了大概半条街，你忽然觉得口袋里有什么东西在响——是那枚抹茶汽水的瓶盖。你把它摸出来，正准备扔进路边的垃圾桶，手指碰到了瓶盖上贴着的东西。

一张小小的便签。三玖的字迹，小得几乎看不清：

「今天谢谢。虽然不知道你在想什么。」

你站在路灯下看了几秒。便签背面还有一行字，更小，像是犹豫了很久才写上去的：

「图书室。午休。我每天都在。」

没有署名。也不需要署名。

（背景切换 → 公寓外 · 夜风）

你回头看了一眼公寓的方向。走廊尽头的窗户亮着灯，窗帘拉得严严实实。你想起她今天在厨房问你「要留下来吃饭吗」时的表情——像是问出口就已经用掉了全部的勇气。

你把便签折好，放进钱包的夹层里。然后继续朝车站走。

明天午休。图书室。
