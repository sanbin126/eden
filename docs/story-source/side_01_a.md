# 番外 · 天台的温度

> 说明：本章按剧本原文录入，与游戏内 JSON 一致。

**简介：**初见当晚，你刚走出公寓大门，身后传来一阵急促的脚步声。

## 场景 · scene_gate　公寓外 · 夜风

你离开中野家之后，走出公寓大门，夜风从领口灌进来。你把手插进口袋，摸到那枚抹茶汽水的瓶盖，正想把它扔进路边的垃圾桶——

身后传来一阵急促的脚步声。很轻，但在安静的住宅区里格外清晰。

你回头。三玖站在公寓门口的台阶上，没有穿外套，脖子上挂着那副蓝色耳机。她大概是跑下来的，呼吸有点乱，刘海被风吹得更散了一些。

〖三玖〗「……等一下。」

她停在离你三步远的地方，像是不知道接下来该说什么。手指在耳机线上绕了一圈。

〖三玖〗「你……明天还会来吗。」

**※选项：**

- 「会。我说了会认真做。」（三玖好感 0）
- 「你希望我来吗？」（三玖好感 0）

## 场景 · scene_branch_a　公寓外 · 夜风

三玖低下头，刘海遮住了大半表情。过了两秒，她轻轻「嗯」了一声，声音小得像是在自言自语。

〖三玖〗「……那明天。图书室。午休。」

她说完就转身跑回了公寓，没有给你回答的时间。你听到她在门厅里差点绊了一跤的声音，然后是一句压低了的「没事」。

## 场景 · scene_branch_b　公寓外 · 夜风

三玖的手指在耳机线上停住了。她偏过头，刘海下的视线飘向一边。

〖三玖〗「……随便你。」

顿了一下。又补了一句，更小声。

〖三玖〗「……但如果你来的话，我大概会在。」

她没等你回答就转身走了。这次走得很慢，慢到你能看到她的耳朵尖在路灯下泛着红。

## 场景 · scene_after　公寓外 · 夜风

你站在原地，把瓶盖重新放回口袋。公寓门口已经没人了，但二楼的窗户亮了一盏灯，窗帘动了一下，又不动了。

**※章节结束。**
