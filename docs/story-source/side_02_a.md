# 番外 · 回家路上的抹茶汽水

> 说明：本章按剧本原文录入，与游戏内 JSON 一致。

**简介：**你刚要走，三玖追了出来，往你手心里塞了一枚瓶盖。

## 场景 · scene_gate　公寓外 · 夜风

你走出中野家公寓，手里还攥着那瓶抹茶汽水——三玖买的那瓶，喝了一半，瓶身已经被手心的温度捂得不再冰凉。你正想把空瓶扔进门口的回收箱，身后传来一阵脚步声。

这次是三玖追出来了。

她穿着家居服，脚上是拖鞋，头发有点乱。大概是急着下楼，连外套都没披。她走到你面前，停下，呼吸有点急。

〖三玖〗「……那个。」

她看着你手里的空瓶，像是在确认什么。

〖三玖〗「明天。图书室。你说过会去。」

〖你〗「我说过。」

她点了点头，动作很轻。然后从睡衣口袋里摸出一样东西，递过来——是一枚新的瓶盖。抹茶汽水的，和她今天买的那瓶一模一样。

〖三玖〗「……给你。你那个，不是拧下来了吗。」

**※选项：**

- 「你特意买的？」（三玖好感 0）
- 「这算是……回礼？」（三玖好感 0）

## 场景 · scene_branch_a　公寓外 · 夜风

三玖的视线偏开了。

〖三玖〗「……自动贩卖机多找的。」

那个理由显然站不住脚。但她没有给你追问的机会，把瓶盖塞进你手心，转身就往回走。

走了几步，又停下。

〖三玖〗「明天。别迟到。」

## 场景 · scene_branch_b　公寓外 · 夜风

〖三玖〗「……不算。」

她顿了一下。

〖三玖〗「算……交换。你喝我的汽水，我给你瓶盖。平了。」

这个逻辑完全不成立。但你收下瓶盖的时候，看到她的嘴角弯了一下，很小，在路灯下几乎看不清。

## 场景 · scene_after　公寓外 · 夜风

你站在原地，把那枚瓶盖和之前的放在一起。两枚抹茶汽水的瓶盖，一模一样的绿色。公寓二楼的窗户亮着灯，窗帘拉开了一条缝，然后很快合上了。
