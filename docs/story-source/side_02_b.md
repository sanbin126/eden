# 番外 · 一个人的书架

> 说明：本章按剧本原文录入，与游戏内 JSON 一致。

**简介：**第二天的图书室，借阅台上放着一本《信长公记》，扉页里夹着一张便签。

## 场景 · scene_night　公寓外 · 夜风

你走出中野家公寓。夜风比傍晚凉了不少，你把外套领子竖起来，朝车站走。

（背景切换 → 街道 · 路灯 · 夜）

走到公寓拐角的时候，你无意间回头看了一眼。二楼的窗户亮着灯，但走廊尽头那扇门——三玖的房间——门缝下的光灭了。

你想起晚饭时她坐在桌子对面，碗里的饭几乎没动。想起她在厨房里背对着所有人翻锅，锅铲搅动的速度比平时快。想起她门后那句「谢谢你没有走开」，说完就把门关上了。

（背景切换 → 车站 · 长椅 · 夜）

你走到车站，在长椅上坐下来等车。口袋里的手机震了一下。是一封邮件，发件地址是一串没有备注的号码。

「今天谢谢你。接龙，下次我不会输。」

没有署名。但你知道是谁。

你盯着屏幕看了一会儿，正准备回复，又来了一封。更短：

「晚安。」

你回了一个「晚安」。然后合上手机，看着车站的灯。

（背景切换 → 学校 · 图书室 · 午休）

第二天午休，图书室。你走进去的时候，历史区那排书架前没有人。但借阅台上放着一本书——《信长公记》，借阅卡上写着「中野三玖」，旁边用铅笔轻轻写了一行小字：

「先借给你。我看过了。」

你翻开书。扉页里夹着一张便签，和昨晚邮件一样的字迹：

「看完告诉我感想。我在天台。」

**※章节结束。**
